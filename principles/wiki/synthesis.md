# 学习科学综合报告：理论基础与 v0.2 规划提案

> 依据三份深挖笔记：`raw/learning-science-core.md`（55KB）、`raw/ai-learning-2025-2026.md`（49KB）、`raw/memory-pkm-evidence.md`（40KB）。
> 方法：只采信有对照/元分析/大样本支持的结论；证据空白明示；对外表述按证据分级。

## 一、执行摘要

**三路证据的共同结论**：真正促进长期保持的是**检索练习（g≈0.37-0.61）+ 间隔（g≈0.20-0.54）+ 反馈 + 元认知校准**；划重点/重读/总结是低效用；远迁移基本不存在。AI 辅助学习是双刃剑——**决定正负的不是模型强弱，而是 AI 替学习者完成了哪一段认知劳动，以及之后是否在无 AI 条件下被检验**（宾大 PNAS：练习 +127% 但撤走 AI 后考试 −17%；中国 2.7 万人面板：作业 +18% 但月考 −20%）。

**brainup 的根本张力**：LLM Wiki 模式天然是"高认知卸载"形态——LLM 做总结、交叉引用、一致性维护。这在**簿记层是纯收益**（Karpathy 模式的核心洞察），但在**学习层恰好命中 AI 替代思考的全部风险机制**。这正是本报告要解决的设计矛盾。

**核心判断：编译与学习必须分家。**
- 编译（LLM 做）：链接、去重、格式、一致性、索引——用户不因此失去任何学习动作
- 学习（用户做）：复述、预测、举例、找反例、引用原文、闭卷自测——产品识别并保护这些动作
- 度量（只认真实）：闭卷延迟测验、回访率、校准误差；**AI 开启时的准确率/时长/产物质量只算使用指标**

**v0.2 提案一句话**：先做"复习闭环 MVP"（两键 + 到期提醒 + 复习日志），验证用户会回来；再做"摄入即出题 + 先答后看"的闭环学习流；元认知校准与认知债 lint 作为差异化层。**先验证参与度，再谈学习效果**（Khanmigo 教训：40-47% 学生从未使用，每周 2-5 分钟——剂量是隐藏瓶颈）。

## 二、证据总览

### 2.1 什么真正促进长期保持与迁移（学习科学核心）

| 方法 | 证据级别 | 效应量 | 关键边界 |
|---|---|---|---|
| 练习测试/检索 | A | 实验室 g≈0.50-0.61；课堂 g≈0.37；嵌入式中测 g=0.25 | 必须有反馈；延迟测验才显优势 |
| 分散练习/间隔 | A | 课堂 g≈0.20；应用 d≈0.54 | 最优间隔≈目标保持期 10-20%；初次编码不足时无效 |
| 交错练习 | A− | g≈0.40-0.42 | 只对易混淆类别/需选策略的任务稳定；说明文可能反转 |
| 自我解释 | B+ | g≈0.55 | 需结构化提示与先验知识 |
| 生成效应 | B+ | d≈0.40 | 生成失败且无反馈会固化错误 |
| 元认知校准 | B | 无统一 d | 提示不教知识，须与客观测验绑定 |
| 总结/划重点/重读 | C-D | 低且不稳定 | 不能作为核心机制 |
| 迁移 | — | 近迁移 d≈0.40；**远迁移≈0** | 不要承诺远迁移 |

**关键洞察**：84% 学生用重读、72% 偏好集中练习、主观感受与真实学习可相反（Deslauriers 2019）——**主观感受是坏指标**。实验室到课堂效应量普遍衰减 30-50%。

### 2.2 AI 辅助学习的边界条件（2025-2026 最新）

| 条件 | 结果 | 代表证据 |
|---|---|---|
| AI 直接给答案/代做，之后无 AI 测验 | **负**（−0.17 ~ −1.4 SD） | 宾大 PNAS；中国 2.7 万人面板；CMU 3 RCT |
| AI 只给提示/澄清，学生自己生成 | 中性到正 | CMU hints 组无显著损害 |
| 模型持验证答案 + 强制步骤推进 | **正**（0.3-1.3 SD） | 哈佛物理 RCT 0.63 SD |
| 先尝试→提示阶梯→解法→同构无辅助题 | **正**（练习+学习双增益） | NUMI/Rori/Avanti |
| 有教师/人类监督 | **正**（1.43 vs 0.08） | Gu & Yan 2025 |
| 增补 vs 替代教学环节 | 增补 +0.51；替代无显著 | CMU GAITAR |
| 自愿、无时间表、无剂量 | ≈0（0.06-0.08 SD/年） | Khanmigo |
| 弱先验知识者自由使用 | 更可能受损 | Lehmann 2025 |
| **用时显著缩短 + 分数显著提高** | **强预警信号**（外包） | Strömberg 2026 |

**正面上限**：≈人类导师（元分析 g≈0.36-0.68；2σ 不可复现）。**最强调节变量是教学法而非模型版本**。MIT 认知债的可用信号：83% 的人引用不出自己刚写的话。

### 2.3 记忆算法与 PKM 的现实核查

- **FSRS**：预测精度真实领先（LogLoss 0.337-0.346 vs SM-2 0.373-0.437），但**"预测更准"≠"更会学"**——无任何"学得更好"的 RCT；默认参数版甚至输给常数基线（价值在用自己的日志调参）；"省 20-30% 复习量"是模拟非实测
- **间隔间隔规律**：Cepeda 2008 最优间隔 = 目标保持期 20-40%（周级）→ 5-10%（年级），对应 desired_retention 90% 默认
- **Anki 真实场景**：小 RCT 支持 1-3 个月保持率提升（d≈0.8），但 2026 系统综述：用客观使用量衡量时关联消失——**自评信心≠成绩**
- **证据纠偏**：手写 vs 键盘（g=+0.144，已被复习抹平）不做卖点；概念图有真证据（ES=0.63）但**必须自己画**，只读图谱 UI 无依据；Zettelkasten 零对照研究；LLM 出题证据最薄（无大样本 RCT）但可做（规则校验+人审+可溯源+改题一等）
- **FSRS 集成**：约 8-12 人日（py-fsrs，MIT）；真正的坑是数据模型（cards 必须是 reviews 的纯函数）、UTC/本地日界、题目供给瓶颈（20 新卡/日≈200 复习/日）

## 三、六条设计公理（三路证据收敛）

1. **检索+反馈是最高杠杆的学习动作**——应做成默认，嵌入流程，而非期末大测
2. **学习证据只在 AI 关闭时采集**——闭卷自测、口述复述、凭记忆重建；AI 开启时的一切指标只算使用量
3. **主观感受是坏指标**——流畅感、满意度、自评信心、使用时长都不可作为学习证据
4. **教学法与任务设计 > 模型与算法**——FSRS 是排程引擎，不是教学法；题目质量决定一切
5. **生成动作必须由学习者完成，AI 只做簿记**——provenance（这段是用户生成还是 AI 生成）是一等字段
6. **参与度/剂量是隐藏瓶颈**——先证明用户会回来，再证明学得更好；复习需求会被放大 10 倍，题目供给必须提前设计

## 四、设计原则（v0.2 的"宪法"）

**原则 1：编译与学习分家。** LLM 只做簿记（链接/去重/格式/一致性/索引）；复述、预测、举例、找反例、引用原文必须留给用户。页面/声明带 `provenance: user|llm` 字段。

**原则 2："不给答案"做成架构，不靠提示词。** 答案可得性由工具调用顺序/权限决定：先交尝试 → 解锁提示阶梯 → 二次失败才给解法 → 立刻一道同构无辅助题。宾大的教训：system prompt 写"请不要直接回答"没用（GPT Base 已带家教指令仍 −17%）。

**原则 3：闭卷证据采集。** query 默认"先答后看"（用户先凭记忆作答，再看 wiki）；复习卡"凭记忆复述→对照"；定期"引用探针"（问用户刚写页面的原文依据）。AI 开启时的正确率不算学习证据。

**原则 4：元认知校准是差异化能力。** 信心评分 + 校准曲线（Brier/校准误差）、延迟自评、"难是设计的一部分"叙事。这是竞品几乎都没做的（社区实现中未见）。

**原则 5：排程交给 FSRS，题目供给由人审把关。** FSRS 只决定"何时复习"；"复习什么"（题目质量）是产品核心。约束：cards 必须是 reviews 的纯函数（守住 .kb 可重建）；统一一侧计算（py-fsrs FSRS-6 vs ts-fsrs FSRS-7 不同 due）；先默认参数，攒够 ~1000 条日志再开优化器。

**原则 6：只宣称有证据的话。** 对外表述按证据分级：A（元分析/RCT）才说"研究支持"；C 级只能叫"设计选择"；证据空白（中文成人自学者、长于 6 个月保持）必须在 README 诚实标注。

## 五、v0.2 功能规划（分阶段）

| 阶段 | 内容 | 证据依据 | 工作量 | 验证风险 |
|---|---|---|---|---|
| **P0 复习闭环 MVP**（1-2 周） | 两键（Again/Good）+ 到期提醒 + append-only review log + 默认参数 FSRS | 间隔 d=0.54；先验证回访率 | 5-7 人日 | **最大不确定性：用户会不会每天回来**（Khanmigo 40-47% 从未使用） |
| **P1 摄入即出题**（2-3 周） | 从 wiki 段落生成检索题（规则校验→人审→入池）、可溯源到段落、"改题"一等交互 | 检索 g=.37-.61；LLM 出题证据薄需护栏 | 8-12 人日 | 题目质量与事实错误；答案泄漏 |
| **P1 先答后看**（1-2 周） | query 默认"用户先凭记忆作答→再展示 wiki 答案"；MCP 工具同步支持 | MIT 引用探针；CMU hints>answers | 4-6 人日 | 用户嫌麻烦流失——用 onboarding 叙事缓解 |
| **P2 元认知层**（2-3 周） | 信心评分 + 校准曲线、延迟测验安排、认知债 lint（用时比骤降/引用密度下降→提示） | 元认知错觉；Strömberg 判别器 | 6-8 人日 | 校准数据量小；提示过度打扰 |
| **P2 交错队列**（1 周） | 按"易混淆簇"混排复习题；说明文类内容不强行交错 | 交错 g=.40 边界明确 | 3-5 人日 | 内容类型判定 |
| **P3 概念图手绘**（2 周） | 用户手动画概念关系图（数字=纸笔），可选关系类型 | Nesbit & Adesope；ES=0.63 | 5-8 人日 | 交互成本 |
| **P3 FSRS 调参/四键** | review log ≥1000 条后开优化器、四键评分、工作量滑杆 | 基准真实领先 | 5-8 人日 | 版本锁 |

**明确不做**：学习风格匹配（证据弱）、手写/纸质卖点（已被推翻）、远迁移承诺（≈0）、打卡/排行驱动（相关性幻觉）、无护栏直接答案（PNAS −17%）、只读图谱 UI（概念图必须自己画）、用自评/时长/满意度当效果指标。

## 六、评估方法（怎么证明没自欺）

**北极星指标**（从 v0.2 第一天埋点）：
1. **闭卷延迟测验正确率**（7 天/30 天）——唯一可信的学习证据
2. **复习回访率**（7 日/30 日 active days）——参与度是学习的前置条件
3. **校准误差**（预测信心 vs 实际正确率的 Brier/校准曲线）
4. **认知债指标**（主题用时比骤降 + 引用密度下降的组合信号）

**禁用指标**：自评学习感、使用时长、满意度、AI 开启时的产物质量。

**实验设计**：同用户 A/B（一半卡进队列 vs 对照）、预注册指标、诚实报告置信区间（参照论文界的教训：裁判间一致性 rho=0.04，绝对分数不可信）。

**验证顺序**（Khanmigo 教训）：先证明"用户会回来"，再证明"学得更好"。P0 阶段若回访率不达标，不应急于做 P1/P2——先解决参与度。

## 七、待讨论的开放问题（需要你拍板）

1. **v0.2 的旗帜**：复习闭环（保守，先验证参与度）vs 闭环学习流（摄入→出题→自测，更完整但风险大）vs 认知债仪表盘（差异化但抽象）？
2. **复习入口形态**：CLI 交互（`brainup review`）vs 导出到 Anki/AnkiConnect vs MCP 工具让 agent 提醒（用户用 Claude Code 时）？（三种可并存，但 v0.2 先做哪个？）
3. **题目来源策略**：LLM 自动出题（人审护栏）vs 用户自建卡 vs 混合（LLM 出题草稿 + 用户改）？（证据都指向"改题"是关键交互）
4. **"先答后看"是否设为 query 默认**？（学习收益明确，但可能劝退部分用户——可做开关+onboarding 叙事）
5. **证据空白的处理**：中文成人自学者没有任何 RCT 覆盖——我们只能"借方向不借数字"。是否接受并在 README 明示？

## 八、诚实声明
