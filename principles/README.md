# principles/ — 学习科学理论基础

> 目的：系统研究"学习这件事本身"，为 brainup 的下一阶段规划提供证据基础（而非凭直觉加功能）。
> 组织沿用 LLM Wiki 模式：`raw/` 原始资料（人写 LLM 读）→ `wiki/` 综合分析（LLM 写人读）。

## 研究问题（驱动 v0.2 规划）

1. 什么方法真正促进**长期保持与迁移**？（检索练习/间隔/交错/生成/自我解释/元认知/认知负荷）
2. **AI 辅助学习**是促进还是替代思考？什么设计能让 AI 增强而非削弱学习？（认知卸载/认知债/导师模式）
3. **记忆算法与自测**的可行性与证据？（FSRS 集成成本、LLM 自动出题质量、间隔参数选择）
4. **笔记与知识组织**的实证依据是什么？哪些是传说？（手写 vs 数字笔记、概念图、Zettelkasten）
5. 对 brainup 的启示：v0.2 该做哪些学习功能，不该做哪些？
